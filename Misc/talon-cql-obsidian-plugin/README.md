# Talon CQL Obsidian Plugin

Talon CQL is an external community plugin for Obsidian that adds syntax highlighting for CrowdStrike Query Language (CQL) and Falcon LogScale query snippets in notes.

This can be useful for security teams that document threat hunting workflows, DFIR notes, runbooks, detections, investigations, and query examples in Obsidian.

## Links

- Obsidian Community Plugin: https://community.obsidian.md/plugins/talon-cql
- GitHub repository: https://github.com/clivoa/talon-cql

## Features

- Highlights fenced code blocks tagged as `cql` or `logscale`.
- Supports common CQL syntax such as event fields, functions, namespaced functions, operators, comments, strings, regex literals, and numbers.
- Works in Obsidian reading mode and editing mode.
- Includes example query templates for process, network, and identity hunting workflows.

## Install

Install Talon CQL from the Obsidian Community Plugins directory:

https://community.obsidian.md/plugins/talon-cql

Or search for `Talon CQL` in Obsidian under Settings > Community Plugins.

## Note

Talon CQL is a community-maintained project and is not an official CrowdStrike product.
